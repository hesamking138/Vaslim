# Vaslim? 🛠️

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Platform](https://img.shields.io/badge/platform-.NET%20MAUI-purple.svg)

**Vaslim?** is a high-performance network diagnostic tool designed for precision connectivity monitoring. While it provides deep insights into general internet health, its specialized latency tracking makes it an indispensable utility for gamers who need to know exactly how their connection performs across global game server clusters.

---

## 🚀 Key Features

### 🌐 Comprehensive Network Diagnostics
Monitor your connection stability with real-time data on:
* **HTTP Global Connectivity:** Real-time status and speed monitoring.
* **DNS Resolution:** Check for latency issues in your DNS lookup process.
* **IP Tracking:** Instant visibility of your Public and Local IP addresses.
* **Protocol Testing:** Diagnostic checks for ICMP (Ping), TCP Handshake, and UDP port status.

### 🎮 Gaming-Centric Latency Monitoring
Don't just guess why you're lagging. Vaslim? allows you to select specific game environments to check ping across global regions for:
* **Fortnite**
* **World of Warcraft**
* **League of Legends**
* **War Thunder**
* *And more (Minecraft, Overwatch 2, Roblox, etc.)*

## ⚖️ Disclaimer

**Vaslim?** is a diagnostic tool intended for network troubleshooting and performance monitoring. It does not "reduce" ping or provide "gaming hacks"; it provides the **data** you need to understand your connection quality and troubleshoot network issues effectively.
